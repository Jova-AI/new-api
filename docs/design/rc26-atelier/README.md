## 设计方向

Atelier 是本次视觉方案的名称，产品身份仍为 Token Center。

采用暖白纸面、墨绿导航与苔绿色强调色，建立安静、清晰的工作空间。首页使用衬线大标题、非对称构图和统一网关示意图；控制台使用深色侧栏、连续指标分区、低饱和图表与紧凑日志表格。通过布局、字号层次、材质感和信息组织整体改变视觉，而不止更换主题色。

| 角色 | 色值 |
| --- | --- |
| 页面底色 | `#F6F5EF` |
| 主文字 | `#213E33` |
| 操作与品牌强调 | `#214D3D` |
| 激活导航 | `#D9E7AD` |
| 面板 | `#FFFEFA` |
| 分隔线 | `#DEDFD5` |

正文采用系统无衬线字体，中文优先 Noto Sans CJK SC；展示标题采用 Georgia / Noto Serif CJK SC；技术标识采用等宽字体。手机端首页纵向排列、指标变为两列、图表变为单列，日志表格在自身容器内横向滚动。手机控制台导航的抽屉交互留待正式组件实现。
